# Regras para Arquivos Markdown (.md)

Ao criar ou modificar qualquer arquivo Markdown (`.md` ou `.markdown`):

- O limite máximo de tamanho de linha é estritamente **120 caracteres** (regra MD013 do `markdownlint`).
- Nenhuma linha de texto, tópicos ou documentação deve exceder 120 caracteres.
- Ao adicionar parágrafos ou itens de lista, quebre as linhas para manter todas abaixo de 120 caracteres.
